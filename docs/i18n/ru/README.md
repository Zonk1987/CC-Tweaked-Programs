## 🏗️ Архитектура: Модульный скелет Feature-Core

Этот репозиторий спроектирован для максимальной простоты обслуживания и высокой производительности с использованием модульной структуры.

### **Ядровые модули (`lib/core`)**
Общие вспомогательные утилиты вынесены в скрытые пакеты ядра для устранения дублирования кода:
- **`core.base`**: Фундаментальная логика, такая как `ConfigStore` (сохранение данных в формате JSON).
- **`core.peripherals`**: Безопасный поиск и подключение периферийных устройств (`PeripheralScanner`).
- **`core.network`**: Стандартизированные протоколы беспроводной модемной связи (`RednetProtocol`).
- **`core.redstone`**: Помощники для взаимодействия со сигналами красного камня (`RedstoneController`).
- **`core.ui`**: Компоненты графического интерфейса для повторного использования (`ButtonGrid`).
- **`core.inventory`**: Стандартизированная обработка инвентаря и перемещения предметов (`InventoryAdapter`, `ItemMatcher`).
- **`core.recipes`**: Хранилище рецептов с резервным копированием в JSON (`RecipeStore`).

### **Автоматическое разрешение зависимостей**
Установщик автоматически рекурсивно разрешает зависимости. Например, установка программы `create_crafter` автоматически загрузит необходимые вспомогательные модули `core.inventory` и `core.redstone`. Файлы приложений размещаются в корневом каталоге компьютера, а библиотеки ядра хранятся в иерархии `lib/core/` (доступ к ним настраивается через пути пакетов в файле запуска `startup.lua`).

## 🛠️ Руководство по разработке

### **Добавление нового приложения**
1. Создайте папку для вашего приложения (например, `My New App`).
2. Реализуйте логику программы, используя готовые ядровые модули из `lib/core`.
3. Зарегистрируйте ваше приложение в манифесте `manifest.lua`.
4. Укажите зависимости, если используете ядровые модули.

### **Добавление нового модуля ядра**
1. Разместите файл модуля по пути `lib/core/<категория>/ModuleName.lua`.
2. Зарегистрируйте его как скрытый пакет (`hidden = true`) в `manifest.lua`.

## ⚖️ Правила безопасности и стандарты кода

Весь код в данном репозитории подчиняется правилам **[AGENTS.md](./AGENTS.md)**.
- **Строгий режим (Strict Mode)**: Скрипты приложений и загрузочные файлы работают в строго изолированной среде во избежание случайного засорения глобального пространства переменных (библиотеки ядра временно пропускают это требование для минимизации кода локализации).
- **Сохранение данных**: Установщик никогда не удаляет существующие пользовательские файлы (за исключением очистки собственных временных файлов, таких как `manifest.lua` и `install.lua` после установки, или замены устаревших версий при обновлении).
- **Кэш состояния установки**: Установщик создает скрытый файл `.install_state.json` для отслеживания установленных версий файлов. Это ускоряет последующие запуски за счет пропуска неизмененных файлов (отображается как `CACHED`). Файл можно безопасно удалить в любое время — в этом случае следующая установка просто загрузит все заново.
- **Без автоперезагрузки**: Установщик всегда спрашивает разрешения перед запуском входных скриптов и никогда не перезагружает систему компьютера без подтверждения от игрока.
- **Одно приложение на компьютер**: На одном компьютере официально поддерживается только **одно** приложение. Установка нескольких программ приведет к конфликтам файлов и перезаписи критически важных запускаемых файлов, таких как `startup.lua` или `Dashboard.lua`.
