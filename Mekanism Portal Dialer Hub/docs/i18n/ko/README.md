# 메카니즘 포털 네트워크(CC:Tweaked)

> **Mekanism Teleporters**를 위한 전문적인 고성능 터치 인터페이스입니다. 깜박임 없는 이중 버퍼 UI, 다중 페이지 주파수 관리 및 색상 사용자 정의가 가능한 내장 주파수 편집기가 특징입니다.


---

## ✨ 특징

- **이중 버퍼 렌더링** — 사용자 정의 창 기반 버퍼 시스템을 사용하여 깜박임 없는 UI 업데이트.
- **이동 가능한 오버레이 창** — 최적의 가시성을 위해 화면 아무 곳이나 색상 선택 메뉴를 드래그하세요.
- **악센트 줄무늬 표시기** — 버튼의 고대비 수직 막대는 어떤 배경에서도 잘 보이도록 검정색 그림자 테두리로 할당된 색상을 표시합니다.
- **동적 포털 그리드** — 스마트 페이지 매김 및 목록 변경 시 자동 **페이지 재설정**을 통해 모든 주파수를 자동으로 검색합니다.
- **실시간 상태 모니터링** — 포털 상태, 대상 빈도 및 소유자(Mojang UUID 확인 포함)에 대한 실시간 피드백입니다.
- **편집 모드 및 색상 사용자 정의** — 특정 색상을 주파수에 할당하거나 임의의 색상 주기를 사용합니다.
- **원격 리콜 지원** — 원격 포털 활성화를 위한 통합 모뎀 및 Rednet API(Recaller 스크립트를 통해).

## 🛠️ 하드웨어 설정

![Ingame Setup](../../assets/images/hub-setup.png)


1. **고급 컴퓨터** — 고해상도 그래픽 및 이중 버퍼링에 필요합니다.
2. **고급 모니터**
- 권장 크기: 최상의 버튼 레이아웃을 위한 **4x3 블록**.
- **유선 모뎀** 및 네트워킹 케이블을 통해 연결합니다.
3. **메카니즘 텔레포터**
- **유선 모뎀**을 사용하여 텔레포터를 동일한 케이블 네트워크에 연결하세요.
- 모뎀을 마우스 오른쪽 버튼으로 클릭하여 모뎀을 **ON**(빨간색 고리)으로 설정합니다.
4. **모뎀(선택 사항)**
- **원격 호출** 기능을 활성화하려면 무선 또는 유선 모뎀을 컴퓨터에 연결하십시오.

## 🚀 설치

1. 저장소에서 install.lua 파일을 다운로드합니다.
```bash
wget https://raw.githubusercontent.com/Zonk1987/CC-Tweaked-Programs/main/install.lua
```
2. install.lua 파일을 실행하세요
```bash
install.lua
```
메뉴에서 **Mekanism Portal Dialer Hub**를 선택합니다. 설치 프로그램은 자동으로 앱 파일(`HubSystem`, `UUIDService`, `Dashboard`)을 다운로드하고 모든 핵심 종속성(예: `ButtonGrid`, `PeripheralScanner`)을 해결합니다.

## ⚙️ 구성

이 시스템은 주변 장치 설정을 쉽게 사용자 정의할 수 있도록 그래픽 기반 대화형 구성 메뉴를 제공합니다.

- **설정 구성**: 언제든지 다음 명령을 실행하여 구성 UI를 실행할 수 있습니다.
  ```bash
  startup.lua --config
  ```
  또는:
  ```bash
  startup.lua -c
  ```
  이를 통해 모니터와 텔레포터 방향을 동적으로 선택할 수 있습니다. 설정은 `config.json`에 저장됩니다.
- **고급 옵션**: 그리드 크기 또는 호출 채널을 맞춤설정하려면 생성된 `config.json` 파일을 직접 편집할 수 있습니다.
  - `"gridColumns"` / `"gridRows"`: 버튼 레이아웃을 조정합니다(기본값: 4x4).
  - `"recallChannel"`: 원격 포털 요청을 위한 모뎀 채널을 설정합니다(기본값: 99).

## ⌨️ 컨트롤 및 모드

### **다이얼러 모드(기본값)**
- **포털을 탭하세요** — 텔레포터 주파수를 즉시 전환합니다. 하드웨어가 변경 사항을 확인할 때까지 버튼은 강조 표시된 상태로 유지됩니다.
- **다음/이전** — 빈도가 많은 경우 페이지 간에 전환합니다.

### **편집 모드(설정 아이콘)**
1. 오른쪽 상단에 있는 **¤** 아이콘을 눌러 편집 모드로 들어갑니다.
2. 포털을 선택하여 **색상 오버레이**를 엽니다.
3. 특정 포털에 대해 **고정 색상**을 선택하거나 동적 색상 순환을 위해 **무작위**를 선택합니다.
4. 창으로 인해 시야가 차단되는 경우 오버레이 상단에 있는 **이동** 막대를 사용하여 창을 이동하세요.

## 📝 원격 리콜 API

시스템은 구성된 `recallChannel`에서 모뎀 메시지를 수신합니다. 포털을 원격으로 트리거하려면 다음 구조의 테이블을 보내세요.
```lua
{
    command = "RECALL",
    target = "My Base" -- Name of the frequency
}
```
또는 휴대용 포켓 컴퓨터에서 전용 **Mekanism Portal Recaller** 스크립트를 사용할 수 있습니다.
