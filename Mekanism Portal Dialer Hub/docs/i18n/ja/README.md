## 構成

コンピュータで「スタートアップ」を開いて、システムの動作をカスタマイズします。

- `gridColumns` / `gridRows`: ページごとのボタンの数を調整します。

## 「リモートリコールAPI」

システムは、設定された `recallChannel` でモデム メッセージをリッスンします。ポータルをリモートでトリガーするには、次の構造のテーブルを送信します。
```lua
{
    command = "RECALL",
    target = "My Base" -- Name of the frequency
}
```
あるいは、ハンドヘルド ポケット コンピュータで専用の **Mekanism Portal Recaller** スクリプトを使用することもできます。
