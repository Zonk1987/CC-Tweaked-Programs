# Сеть порталов Mekanism (CC:Tweaked)

> Профессиональный высокопроизводительный сенсорный интерфейс для **телепортов Mekanism**. Имеет пользовательский интерфейс с двойной буферизацией без мерцания, многостраничное управление частотой и встроенный редактор частот с настройкой цвета.


---

## ✨ Особенности

- **Рендеринг с двойной буферизацией** — обновления пользовательского интерфейса с нулевым мерцанием с использованием специальной оконной буферной системы.
- **Подвижные наложенные окна** — перетащите меню выбора цвета в любое место экрана для оптимальной видимости.
- **Индикаторы акцентных полос** — высококонтрастные вертикальные полосы на кнопках показывают назначенные цвета с черными теневыми границами для видимости на любом фоне.
- **Динамическая сетка портала** — автоматически обнаруживает все частоты с помощью умной нумерации страниц и автоматического **сброса страницы** при изменении списка.
- **Мониторинг статуса в режиме реального времени** — оперативная обратная связь о статусе портала, целевой частоте и владельце (с разрешением Mojang UUID).
- **Режим редактирования и настройка цвета** — назначьте определенные цвета частотам или используйте случайный цветовой цикл.
- **Поддержка удаленного вызова** — интегрированный модем и API Rednet для удаленной активации портала (через скрипт Recaller).

## 🛠️ Настройка оборудования

![Ingame Setup](../../assets/images/hub-setup.png)


1. **Продвинутый компьютер** — требуется для графики высокого разрешения и двойной буферизации.
2. **Расширенный монитор**
- Рекомендуемый размер: **блоки 4x3** для оптимального расположения кнопок.
- Подключайтесь через **Проводные модемы** и сетевые кабели.
3. **Телепорт Меканизма**
- Подключите Телепорт к той же кабельной сети с помощью **Проводного модема**.
- Щелкните правой кнопкой мыши модем, чтобы включить его **ВКЛ** (красное кольцо).
4. **Модем (дополнительно)**
- Подключите беспроводной или проводной модем к компьютеру, чтобы включить функцию **Удаленного вызова**.

## 🚀 Установка

1. Загрузите файл install.lua из репозитория.
```bash
wget https://raw.githubusercontent.com/Zonk1987/CC-Tweaked-Programs/main/install.lua
```
2. Запустите файл install.lua.
```bash
install.lua
```
В меню выберите **Mekanism Portal Dialer Hub**. Установщик автоматически загрузит файлы приложения («HubSystem», «UUIDService», «Dashboard») и разрешит все основные зависимости (например, «ButtonGrid», «PeripheralScanner»).

## ⚙️ Конфигурация

Откройте «Автозагрузка» на компьютере, чтобы настроить поведение системы:

- `gridColumns` / `gridRows`: отрегулируйте количество кнопок на странице.
- `recallChannel`: Установите канал модема для запросов удаленного портала (по умолчанию: 99).

## ⌨️ Элементы управления и режимы

### **Режим набора номера (по умолчанию)**
- **Нажмите на портал** — мгновенное переключение частоты телепорта. Кнопка будет оставаться выделенной до тех пор, пока оборудование не подтвердит изменение.
- **Следующий/Предыдущий** — переключение между страницами, если у вас много частот.

### **Режим редактирования (значок настроек)**
1. Нажмите значок **¤** в правом верхнем углу, чтобы войти в режим редактирования.
2. Выберите любой портал, чтобы открыть **Наложение цвета**.
3. Выберите **Фиксированный цвет** для конкретного портала или выберите **СЛУЧАЙНЫЙ** для динамической смены цветов.
4. Используйте панель **MOVE** в верхней части наложения, чтобы сдвинуть окно, если оно закрывает вам обзор.

## 📝 API удаленного отзыва

Система прослушивает сообщения модема на настроенном канале RecallChannel. Чтобы запустить портал удаленно, отправьте таблицу следующей структуры:
```lua
{
    command = "RECALL",
    target = "My Base" -- Name of the frequency
}
```
Альтернативно, вы можете использовать специальный скрипт **Mekanism Portal Recaller** на портативном карманном компьютере.
