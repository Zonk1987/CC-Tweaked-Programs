# CC-Tweaked Automations

> A collection of professional, production-ready ComputerCraft / CC:Tweaked automation scripts. All systems feature live terminal dashboards, strict modular architecture, and seamless integration with **AE2**, **Refined Storage**, and **Create**.

---

## 🚀 Universal Installer

Install **any** program with a single command on your ComputerCraft terminal:

```bash
wget https://raw.githubusercontent.com/Zonk1987/CC-Tweaked-Programs/main/Universal%20Installer/install.lua
install
```

An interactive menu will appear, allowing you to select and install any system listed below. The installer automatically handles dependencies and initial setup.

## 📂 Projects

### ⚡ [Powah Energizing Orb Automation](./Powah%20Energizing%20Orb%20Automation/)
*High-performance energy crafting with parallel processing.*
- **AE2 ME Bridge Support**: Direct pattern import via GUI (Hotkey `I`).
- **Multi-Orb Scaling**: Automatic discovery and parallel crafting across all connected orbs.
- **Auto-Recovery**: Intelligent item retrieval and power-loss protection.
- **Standardized Storage**: Uses `powah_recipes.json` for easy pattern management.

### 🌌 [Mekanism Portal Dialer Hub](./Mekanism%20Portal%20Dialer%20Hub/)
*Premium touch-interface for interdimensional travel.*
- **Double-Buffered UI**: Flicker-free rendering on Advanced Monitors.
- **Edit Mode**: Visual frequency editor with custom color assignments and owner detection.
- **Remote Recall**: Integrated Rednet support for remote dialing.

### 📡 [Mekanism Portal Recall Sender](./Mekanism%20Portal%20Dialer%20Recall%20Sender/)
*Remote triggers for the Portal Hub system.*
- **Wireless Triggering**: Dial home from any dimension with a single redstone pulse.
- **Easy Calibration**: Interactive setup wizard to link the sender to destination names.

### 🛠️ [CC Developer Suite](./CC%20Developer%20Suite/)
*The power-user's diagnostic toolkit.*
- **Superior Inspector**: Interactive method exploration for any connected peripheral.
- **Item Browser**: Deep-dive into inventory NBT data and registry names.
- **Input Guard**: Integrated delays to prevent accidental double-inputs in diagnostic menus.

### ⚙️ [Create Mechanical Crafter](./Create%20Mechanical%20Crafter%20Automation/)
*Fully automated grid crafting for the Create mod.*
- **Visual Management**: Press `M` to browse, inspect, and delete recipes in-game.
- **In-Game Recording**: Create patterns by placing items in the grid and pressing `S`.
- **Smart Calibration**: Automatic discovery of grid layout via modem clicks.
