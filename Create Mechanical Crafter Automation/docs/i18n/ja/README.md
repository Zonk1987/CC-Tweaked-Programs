## 📖 使用方法

### 新しいレシピを記録する
1. 材料を物理的な機械式クラフターに手動で配置します。
2. ダッシュボードで **`S`** を押します。
3. 名前を入力し、**ENTER** を押します。システムはグリッドをスキャンし、即座に保存します。

### レシピの管理
1. ダッシュボードで **`M`** を押してマネージャーを開きます。
2. レシピを参照し、材料を表示し、**`X`** を押して古いパターンを削除します。

---

## ⌨️ ホットキー

| 鍵 | アクション |
|:---:|---|
| **「す」** | **スキャン/記録** グリッドから新しいレシピ *(名前を空にして Enter キーを押してキャンセルします)* |
| **「ん」** | **保存されたレシピを管理**し、パターンを表示します |
| **`R`** | **レシピを「crafter_recipes.json」からリロード** |
| **「Q」** | **終了** (レシピ マネージャー メニューを終了し、ダッシュボードに戻ります) |
