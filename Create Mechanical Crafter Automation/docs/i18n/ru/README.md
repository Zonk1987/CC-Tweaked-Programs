# Создайте автоматизацию Mechanical Crafter 🛠️

> Полностью автоматизированная, готовая к производству система ComputerCraft для **Mechanical Crafters** из мода **Create**. Разработан для полной интеграции с AE2/Refined Storage в **режиме блокировки**.


---

## ✨ Особенности

- **Запись рецептов в игре** — Поместите предметы в крафтеры, нажмите «S», введите имя. Сделанный. Редактирование JSON не требуется.
- **Визуальное управление рецептами** — нажмите «M», чтобы просмотреть все сохраненные рецепты, просмотреть необходимые ингредиенты и управлять шаблонами.
- **Интерактивная калибровка сетки** — автоматическое определение точного расположения сетки посредством последовательной активации модема.
- **Готовность к режиму блокировки AE2 / RS** — оптимизирована для интеграции буферного хранилища с гарантированной обработкой одного корабля.
- **Интеллектуальное обнаружение замятия** — оповещения в режиме реального времени, показывающие точный слот крафтера и предмет, вызывающий узкие места.
- **Интерактивная панель** — высокопроизводительный пользовательский интерфейс с цветовой кодировкой, показывающий состояние сетки, историю заданий и недостающие ингредиенты.

## 🛠️ Настройка оборудования

![Ingame Setup](../../assets/images/crafter-setup.png)


1. **Продвинутый компьютер** — требуется для цветной приборной панели с высоким разрешением.
2. **Crafter Grid** — создайте массив (например, 3х3, 5х5, 9х9).
3. **Сетевое взаимодействие (важный шаг):**
- Подключите **Проводной модем** к **каждому** механическому мастеру.
- Подключите все модемы к компьютеру с помощью **сетевых кабелей**.
- Щелкните правой кнопкой мыши по модемам, пока не загорится **красное кольцо**.
- **⚠️ ВАЖНО:** Вы ДОЛЖНЫ активировать модемы в **порядке чтения** (верхний левый → верхний правый, затем ряд за рядом) во время калибровки.
4. **Буферный сундук**. Подключите сундук (например, Алмазный сундук), расположенный рядом с компьютером, через проводной модем.
5. **Триггер Redstone** — подключите сигнал Redstone с **любой стороны** компьютера к Crafters.

## 🚀 Установка и использование

1. Загрузите файл install.lua из репозитория.
```bash
wget https://raw.githubusercontent.com/Zonk1987/CC-Tweaked-Programs/main/install.lua
```
2. Запустите файл install.lua.
```bash
install.lua
```
3. Выберите **Создать Mechanical Crafter Automation**.
4. **Калибровка**: при первом запуске следуйте инструкциям на экране и щелкайте модемы правой кнопкой мыши по порядку. Это сопоставляет физическую сетку с программным обеспечением.
5. **Режим блокировки**: установите для поставщика шаблонов AE2 режим **"Режим блокировки"**, обращенный к буферному сундуку.

## 📖 Как использовать

### Запись нового рецепта
1. Поместите ингредиенты вручную в физические механические мастера.
2. Нажмите **`S`** на приборной панели.
3. Введите имя и нажмите **ENTER**. Система сканирует сетку и мгновенно сохраняет ее!

### Управление рецептами
1. Нажмите **`M`** на панели управления, чтобы открыть диспетчер.
2. Просмотрите рецепты, просмотрите ингредиенты и нажмите **`X`**, чтобы удалить старые шаблоны.

## ⌨️ Горячие клавиши

| Ключ | Действие |
|:---:|---|
| **`S`** | **Сканировать/Записать** новый рецепт из таблицы *(Отменить, нажав ENTER с пустым именем)* |
| **`М`** | **Управляйте** сохраненными рецептами и просматривайте шаблоны. |
| **`Р`** | **Обновить** рецепты из `crafter_recipes.json` |
| **`Q`** | **Выход** (выйдите из меню «Менеджер рецептов» и вернитесь на панель управления) |

## ⚙️ Конфигурация

Система оснащена интерактивным графическим меню настройки для легкого изменения параметров:

- **Изменение настроек**: Вы можете запустить интерфейс настройки в любое время, выполнив команду:
  ```bash
  startup.lua --config
  ```
  или:
  ```bash
  startup.lua -c
  ```
  Это позволит вам выбрать буферный сундук и динамически настроить цвет текста на панели управления.
- **Перекалибровка**: Физическая привязка модемов хранится в файле `crafter_mapping.json`. Чтобы заново откалибровать сетку (например, если вы изменили расположение Mechanical Crafters), просто удалите файл `crafter_mapping.json` и запустите программу в обычном режиме.

## 🛑 Устранение неполадок

| Ошибка | Причина и решение |
|---|---|
| `Буферный сундук отсутствует!` | Модем на груди выключен или отключен. |
| «Нет мастерам-механикам!» | Модемы не найдены. Проверьте кабели и красные кольца! |
| `ЗАСТРЯЛО: Слот #X` | Изготовление не закончилось. Проверьте импульс и мощность красного камня. |
| «Несоответствие шаблону» | Неправильные элементы в сетке или файл сопоставления поврежден. Перекалибровать! |
