# 기계 제작 자동화 만들기 🛠️

> **Create** 모드의 **Mechanical Crafters**를 위한 완전 자동화된 생산 준비 ComputerCraft 시스템입니다. **차단 모드**에서 AE2/Refined Storage와 원활하게 통합되도록 설계되었습니다.


---

## ✨ 특징

- **게임 내 레시피 기록** — 크래프터스에 아이템을 넣고 `S`를 누르고 이름을 입력하세요. 완료. JSON 편집이 필요하지 않습니다.
- **시각적 레시피 관리** — 'M'을 누르면 저장된 모든 레시피를 검색하고 필요한 재료를 확인하며 패턴을 관리할 수 있습니다.
- **대화형 그리드 보정** — 순차 모뎀 활성화를 통해 정확한 그리드 레이아웃을 자동으로 감지합니다.
- **AE2 / RS 차단 모드 준비** — 단일 공예 처리가 보장된 버퍼 상자 통합에 최적화되었습니다.
- **스마트 잼 감지** — 병목 현상을 일으키는 정확한 제작 슬롯과 아이템을 보여주는 실시간 알림입니다.
- **라이브 대시보드** — 그리드 상태, 작업 기록 및 누락된 재료를 표시하는 색상으로 구분된 고성능 UI입니다.

---

## 🛠️ 하드웨어 설정

![Ingame Setup](../../assets/images/crafter-setup.png)


1. **고급 컴퓨터** — 컬러 고해상도 대시보드에 필요합니다.
2. **Crafter Grid** — 배열을 구축합니다(예: 3×3, 5×5, 9×9).
3. **네트워킹(중요한 단계):**
- **모든 단일** Mechanical Crafter에 **유선 모뎀**을 연결하세요.
- **네트워킹 케이블**을 사용하여 모든 모뎀을 컴퓨터에 연결합니다.
- **빨간색 링**이 켜질 때까지 모뎀을 마우스 오른쪽 버튼으로 클릭합니다.
- **⚠️ 중요:** 보정 중에 모뎀을 **읽는 순서**(왼쪽 상단 → 오른쪽 상단, 다음 행별로)로 활성화해야 합니다.
4. **버퍼 상자** — 유선 모뎀을 통해 컴퓨터에 인접한 상자(예: 다이아몬드 상자)를 연결합니다.
5. **레드스톤 트리거** — 컴퓨터의 **모든 측면**에서 Crafters로 레드스톤 신호를 연결합니다.

## 🚀 설치 및 사용

1. 저장소에서 install.lua 파일을 다운로드합니다.
```bash
wget https://raw.githubusercontent.com/Zonk1987/CC-Tweaked-Programs/main/install.lua
```
2. install.lua 파일을 실행하세요
```bash
install.lua
```
3. **기계 제작 자동화 생성**을 선택합니다.
4. **보정**: 처음 시작할 때 화면에 나타나는 지시에 따라 모뎀을 순서대로 마우스 오른쪽 버튼으로 클릭합니다. 이는 물리적 그리드를 소프트웨어에 매핑합니다.
5. **차단 모드**: AE2 패턴 제공자를 버퍼 상자를 향한 **"차단 모드"**로 설정합니다.

## 📖 사용 방법

### 새로운 레시피 기록
1. 물리적 기계 제작기에 재료를 수동으로 넣습니다.
2. 대시보드에서 **`S`**를 누르세요.
3. 이름을 입력하고 **ENTER**를 누릅니다. 시스템이 그리드를 스캔하고 즉시 저장합니다!

### 레시피 관리
1. 대시보드에서 **`M`**을 눌러 관리자를 엽니다.
2. 레시피를 찾아보고 재료를 확인한 다음 **`X`**를 눌러 이전 패턴을 삭제하세요.

---

## ⌨️ 단축키

| 열쇠 | 행동 |
|:---:|---|
| **`S`** | **스캔/기록** 그리드에서 새 레시피 *(이름이 비어 있으면 ENTER를 눌러 취소)* |
| **`엠`** | **관리** 저장된 레시피 및 패턴 보기 |
| **`R`** | `crafter_recipes.json`에서 레시피 **다시 로드** |
| **`Q`** | **종료** (레시피 관리자 메뉴를 종료하고 대시보드로 돌아갑니다) |

## ⚙️ 구성

이 시스템은 설정을 간편하게 맞춤 설정할 수 있는 대화형 그래픽 구성 메뉴를 제공합니다.

- **설정 맞춤화**: 다음 명령을 실행하여 언제든지 구성 UI를 시작할 수 있습니다:
  ```bash
  startup.lua --config
  ```
  또는:
  ```bash
  startup.lua -c
  ```
  이를 통해 버퍼 상자를 선택하고 대시보드 텍스트 색상을 동적으로 변경할 수 있습니다.
- **재보정**: 물리적인 모뎀 레이아웃 매핑은 `crafter_mapping.json`에 저장됩니다. 그리드를 재보정하려면(예: Mechanical Crafter의 배치 설정을 변경한 경우) 단순히 `crafter_mapping.json` 파일을 삭제하고 정상적으로 프로그램을 다시 실행하세요.

## 🛑 문제 해결

| 오류 | 원인 및 수정 |
|---|---|
| '버퍼 상자가 없습니다!' | 가슴의 모뎀이 꺼져 있거나 연결이 끊어졌습니다. |
| '기계 제작자는 안돼!' | 모뎀을 찾을 수 없습니다. 케이블과 빨간색 링을 확인하세요! |
| `잼됨: 슬롯 #X` | 제작이 완료되지 않았습니다. 레드스톤 펄스와 전력을 확인하세요. |
| '패턴 불일치' | 그리드 또는 매핑 파일의 잘못된 항목이 손상되었습니다. 재보정하세요! |
