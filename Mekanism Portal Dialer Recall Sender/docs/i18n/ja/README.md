# Mekanism ポータル リコール送信者 (CC:微調整)

> **Mekanism ポータル ネットワーク** 専用のリモート トリガー。目的地でレッドストーン信号 (ボタン、感圧板など) を提供するだけで、ホーム ポータルにリモートでダイヤルできます。


---

## ✨ 特徴

- **ハードウェア診断** — 起動時に接続されているすべての周辺機器をスキャンし、モデムとテレポーターの存在に関する明確なフィードバックを提供します。
- **ライブ ポータル ステータス (オプション)** — ローカル テレポーター ブロックが物理的に接続されている場合 (それ以外の場合はデフォルトで「リモート ハブのみ」)、ローカル ポータルの状態 (「準備完了」、「電源なし」など) をリアルタイムで監視します。
- **ハートビート自動更新** — 2 秒ごとにステータスを自動的に更新し、表示をハブと同期させます。
- **対話型セットアップ** — コード編集は必要ありません。スクリプトは最初の実行時にターゲットの場所を尋ねます。
- **設定メニュー (ホットキー)** — コンピューター端末で「C」を押して、宛先名またはチャンネルを変更します。
- **デュアルパス プロトコル** - 標準モデム API と Rednet の両方を介してコマンドを送信し、信頼性を最大限に高めます。

---

## 🛠️ ハードウェアのセットアップ

1. **ポケット コンピュータまたは小型コンピュータ** — リモートの目的地 (月面基地、鉱山前哨基地など) にコンピュータを配置します。
2. **モデム (ワイヤレスまたは有線)** — ワイヤレス モデム (遠隔地に最適) または有線モデムをコンピュータに接続します。
3. **レッドストーン トリガー** — ボタン、感圧板、または任意のレッドストーン ソースをコンピューターの任意の側に接続します。
- レッドストーン信号が**オン**になると、コンピューターはメインベースにリコールコマンドを送信します。

## ⚙️使用方法

1. **初回実行**: コンピュータは **ターゲット名** を尋ねます。メイン ポータル ハブに表示される周波数の *正確な名前* を入力します (例: 「メイン ベース」)。
2. **通常の動作**: 画面には「レッドストーン信号を待っています...」と表示されます。
3. **トリガー**: ボタンを押します。メインベースのハブは即座に現在の場所に切り替わります。
4. **設定**: コンピュータを新しい拠点に移動する場合は、キーボードの「C」を押してメニューを開き、ターゲット名を変更します。
