# Отправитель отзыва портала Mekanism (CC:Tweaked)

> Специальный удаленный триггер для **сети порталов Mekanism**. Позволяет удаленно позвонить на ваш домашний портал, просто подав сигнал красного камня (кнопку, нажимную пластину и т. д.) в пункте назначения.


---

## ✨ Особенности

- **Диагностика оборудования** — сканирует все подключенные периферийные устройства при запуске и предоставляет четкую информацию о наличии модема и телепортера.
- **Состояние живого портала (необязательно)** — мониторинг состояния локального портала в режиме реального времени (например, «Готов», «Нет питания»), если локальный блок телепорта физически подключен (в противном случае по умолчанию установлено значение «Только удаленный концентратор»).
- **Автообновление Heartbeat** — автоматически обновляет статус каждые 2 секунды, чтобы обеспечить синхронизацию дисплея с концентратором.
- **Интерактивная настройка** — редактирование кода не требуется. Сценарий запрашивает целевое местоположение при первом запуске.
- **Меню конфигурации (горячие клавиши)** — нажмите `C` на компьютерном терминале, чтобы изменить имя пункта назначения или канал.
- **Протокол двухпутевого доступа** — для максимальной надежности отправляет команды как через стандартный модемный API, так и через Rednet.

---

## 🛠️ Настройка оборудования

1. **Карманный компьютер или маленький компьютер**. Разместите компьютер в удаленном месте (например, на Лунной базе, в горнодобывающей заставе).
2. **Модем (беспроводной или проводной)** — подключите к компьютеру беспроводной модем (идеально подходит для удаленных мест) или проводной модем.
3. **Триггер красного камня**. Подключите кнопку, нажимную пластину или любой источник красного камня к любой стороне компьютера.
- Когда сигнал красного камня включается **ВКЛ**, компьютер отправляет команду отзыва на вашу основную базу.

## 🚀 Установка

1. Загрузите файл install.lua из репозитория.
```bash
wget https://raw.githubusercontent.com/Zonk1987/CC-Tweaked-Programs/main/install.lua
```
2. Запустите файл install.lua.
```bash
install.lua
```
Выберите **Mekanism Portal Recaller** в меню.

---

## ⚙️ Использование

1. **Первый запуск**: компьютер запросит у вас **Имя цели**. Введите *точное название* частоты, как оно отображается в вашем главном Портальном Хабе (например, «Основная база»).
2. **Нормальная работа**: на экране появится сообщение «Ожидание сигнала красного камня...».
3. **Триггер**: нажмите кнопку. Хаб на вашей основной базе мгновенно переключится на ваше текущее местоположение.
4. **Конфигурация**: если вы перемещаете компьютер на новую базу, нажмите клавишу «C» на клавиатуре, чтобы открыть меню и изменить целевое имя.
