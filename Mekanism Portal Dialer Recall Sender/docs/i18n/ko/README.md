# 메카니즘 포털 리콜 발신자(CC:Tweaked)

> **Mekanism Portal Network**를 위한 전용 원격 트리거입니다. 목적지에 레드스톤 신호(버튼, 압력판 등)를 제공하기만 하면 홈 포털에 원격으로 전화를 걸 수 있습니다.

- **하드웨어 진단** — 시작 시 연결된 모든 주변 장치를 검사하고 모뎀 및 텔레포터 존재 여부에 대한 명확한 피드백을 제공합니다.
- **라이브 포털 상태(선택 사항)** — 로컬 텔레포터 블록이 물리적으로 연결된 경우 로컬 포털 상태(예: "준비", "전원 없음")를 실시간으로 모니터링합니다(그렇지 않은 경우 기본값은 "원격 허브만"임).
- **하트비트 자동 새로 고침** — 디스플레이를 허브와 동기화된 상태로 유지하기 위해 2초마다 상태를 자동으로 업데이트합니다.
- **대화형 설정** — 코드 편집이 필요하지 않습니다. 스크립트는 처음 실행 시 대상 위치를 묻습니다.
- **구성 메뉴(단축키)** — 대상 이름이나 채널을 변경하려면 컴퓨터 터미널에서 'C'를 누르세요.
- **이중 경로 프로토콜** — 안정성을 극대화하기 위해 표준 모뎀 API와 Rednet을 통해 명령을 보냅니다.

## ðŸ> ï¸ 하드웨어 설정

1. **포켓 컴퓨터 또는 소형 컴퓨터** — 원격 목적지(예: 달 기지, 광산 전초기지)에 컴퓨터를 배치합니다.

- 레드스톤 신호가 **ON**으로 켜지면 컴퓨터는 주 기지에 회수 명령을 보냅니다.

## ∨ 사용법

1. **첫 번째 실행**: 컴퓨터가 **대상 이름**을 묻는 메시지를 표시합니다. 기본 포털 허브에 나타나는 주파수의 *정확한 이름*을 입력하세요(예: "기본 베이스").
2. **정상 작동**: 화면에 "레드스톤 신호를 기다리는 중..."이 표시됩니다.
3. **트리거**: 버튼을 누릅니다. 주 기지에 있는 허브가 즉시 현재 위치로 전환됩니다.
4. **구성**: 컴퓨터를 새 베이스로 옮긴 경우 키보드의 'C'를 눌러 메뉴를 열고 대상 이름을 변경하세요.
