## ðŸ> ï¸ 주요 도구

### 1. 우수한 주변 검사기
기존 스캐너를 교체합니다. 대화형 명령 목록을 열려면 장치를 선택하세요.
- **화살표(위/아래)**: 사용 가능한 모든 방법을 스크롤합니다.
- **ENTER**: 선택한 방법을 실행하고 결과를 형식화된 테이블로 봅니다.
- **B 키**: **대화형 항목 브라우저**를 실행합니다(장치가 인벤토리인 경우).

### 2. 대화형 아이템 브라우저
모든 인벤토리(상자, AE2 인터페이스, 패턴 제공자)를 자세히 살펴보세요.
- **화살표(위/아래)**: 슬롯을 스크롤합니다.
- **라이브 세부정보**: 선택한 슬롯에 대한 전체 아이템 메타데이터(NBT 태그, 손상, 마법 등)를 실시간으로 표시합니다.
- *AE2 패턴 내부구조 분석에 필수입니다.*

### 3. 이벤트 스니퍼
원시 OS 이벤트에 대한 실시간 모니터입니다. 모든 `mouse_click`, `key`, `redstone` 변경 또는 `modem_message`가 발생하는 대로 표시합니다.

### 4. 레드스톤 분석기
컴퓨터의 6개 측면 모두에 대한 실시간 입력 레벨(0-15)을 동시에 표시합니다.

### 5. 파일 탐색기
시각적 디렉터리 탐색기. 터미널 명령 없이 폴더를 찾아보고, 파일 크기를 보고, 스크립트를 관리하세요.

## ∨ 연결 및 내비게이션
- **단축키 'Q'**: 이전 메뉴로 돌아가거나 도구를 종료합니다.
- **네트워크 토글**: 메인 메뉴에서 Rednet 및 모뎀 지원을 활성화/비활성화합니다.
- **입력 가드(신규)**: 메뉴 탐색 시 실수로 두 번 클릭하는 것을 방지하기 위해 입력 후 0.5초 지연을 통합했습니다.
