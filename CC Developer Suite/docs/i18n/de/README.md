## 🚀 Installation

Führen Sie diesen Befehl auf Ihrem Computer aus:

1. Laden Sie die Datei install.lua aus dem Repo herunter
```bash
wget https://raw.githubusercontent.com/Zonk1987/CC-Tweaked-Programs/main/install.lua
```
2. Führen Sie die Datei install.lua aus
```bash

```
Wählen Sie im Menü **CC Developer Suite** aus.

## 🛠️ Empfohlene Tools

### 1. Überlegener Peripherieinspektor
Ersetzt den alten Scanner. Wählen Sie ein beliebiges Gerät aus, um eine interaktive Befehlsliste zu öffnen.
- **Pfeile (nach oben/nach unten)**: Scrollen Sie durch alle verfügbaren Methoden.
- **ENTER**: Führen Sie die ausgewählte Methode aus und zeigen Sie die Ergebnisse in einer formatierten Tabelle an.
- **B-Taste**: Starten Sie den **Interaktiven Artikelbrowser** (wenn es sich bei dem Gerät um ein Inventar handelt).

### 2. Interaktiver Artikelbrowser
Tauchen Sie tief in jedes Inventar ein (Truhen, AE2-Schnittstellen, Musteranbieter).
- **Pfeile (oben/unten)**: Durch die Slots scrollen.
- **Live-Details**: Zeigt vollständige Gegenstandsmetadaten (NBT-Tags, Schaden, Verzauberungen usw.) für den ausgewählten Slot in Echtzeit an.
- *Unverzichtbar für die Analyse interner Strukturen des AE2-Musters.*

### 3. Ereignis-Sniffer
Ein Echtzeitmonitor für unformatierte Betriebssystemereignisse. Zeigt jeden „Mausklick“, jede „Taste“, jede „Redstone“-Änderung oder jede „Modem_Nachricht“ an, sobald sie auftritt.

### 4. Redstone-Analysator
Zeigt die Live-Eingangspegel (0–15) für alle sechs Seiten des Computers gleichzeitig an.

### 5. Datei-Explorer
Ein visueller Verzeichnisnavigator. Durchsuchen Sie Ordner, zeigen Sie Dateigrößen an und verwalten Sie Ihre Skripte ohne Terminalbefehle.

## ⚙️ Konnektivität und Navigation
- **Hotkey „Q“**: Kehrt zum vorherigen Menü zurück oder beendet das Tool.
- **Netzwerk umschalten**: Rednet- und Modem-Unterstützung über das Hauptmenü aktivieren/deaktivieren.
- **Eingabeschutz (NEU)**: Integrierte Verzögerungen von 0,5 Sekunden nach Eingaben, um versehentliche Doppelklicks beim Navigieren in Menüs zu verhindern.
