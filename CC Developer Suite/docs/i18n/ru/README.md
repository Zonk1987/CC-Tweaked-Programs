## 🚀 Установка

Запустите эту команду на своем компьютере:

1. Загрузите файл install.lua из репозитория.
```bash

```
2. Запустите файл install.lua.
```bash

```
В меню выберите **CC Developer Suite**.

## 🛠️ Рекомендуемые инструменты

### 1. Старший инспектор периферийных устройств
Заменяет старый сканер. Выберите любое устройство, чтобы открыть интерактивный список команд.
- **Стрелки (вверх/вниз)**: прокрутите все доступные методы.
- **ВВОД**: выполнить выбранный метод и просмотреть результаты в отформатированной таблице.
- **Клавиша B**: Запустите **Интерактивный браузер объектов** (если устройство представляет собой инвентарь).

### 2. Интерактивный браузер предметов
Подробно изучите любой инвентарь (сундуки, интерфейсы AE2, поставщики шаблонов).
- **Стрелки (вверх/вниз)**: прокрутка слотов.
- **Живые сведения**: отображает полные метаданные предмета (теги NBT, урон, чары и т. д.) для выбранного слота в режиме реального времени.
- *Необходим для анализа внутренней структуры шаблона AE2.*

### 3. Сниффер событий
Монитор в реальном времени для необработанных событий ОС. Показывает каждое изменение «mouse_click», «key», «redstone» или «modem_message», когда оно происходит.

### 4. Анализатор красного камня
Отображает уровни входного сигнала в реальном времени (0–15) одновременно для всех шести сторон компьютера.

### 5. Проводник файлов
Визуальный навигатор по каталогам. Просматривайте папки, просматривайте размеры файлов и управляйте сценариями без команд терминала.

## ⚙️ Связь и навигация
- **Горячая клавиша «Q»**: возврат в предыдущее меню или выход из инструмента.
- **Переключение сети**: включение/отключение поддержки Rednet и модема в главном меню.
- **Защита ввода (НОВИНКА)**: встроенная задержка 0,5 с после ввода для предотвращения случайных двойных щелчков при навигации по меню.
