# Suite para desarrolladores CC 🛠️🔬

> El conjunto de herramientas definitivo para desarrolladores y usuarios avanzados de **CC:Tweaked**. Análisis profundo de hardware, exploración interactiva de elementos y monitoreo de eventos en tiempo real en un paquete profesional.



---

## 🚀 Instalación

Ejecute este comando en su computadora:

1. Descargue el archivo install.lua del repositorio.
```bash
wget https://raw.githubusercontent.com/Zonk1987/CC-Tweaked-Programs/main/install.lua
```
2. Ejecute el archivo install.lua
```bash
install.lua
```
Seleccione **CC Developer Suite** en el menú.

## 🛠️ Herramientas destacadas

### 1. Inspector Superior de Periféricos
Reemplaza el antiguo escáner. Seleccione cualquier dispositivo para abrir una lista de comandos interactiva.
- **Flechas (arriba/abajo)**: desplazarse por todos los métodos disponibles.
- **ENTER**: Ejecute el método seleccionado y vea los resultados en una tabla formateada.
- **Tecla B**: inicia el **Explorador de artículos interactivo** (si el dispositivo es un inventario).

### 2. Explorador de artículos interactivo
Profundice en cualquier inventario (cofres, interfaces AE2, proveedores de patrones).
- **Flechas (arriba/abajo)**: desplazarse por las ranuras.
- **Detalles en vivo**: muestra los metadatos completos del elemento (etiquetas NBT, daños, encantamientos, etc.) para el espacio seleccionado en tiempo real.
- *Esencial para analizar las estructuras internas del patrón AE2.*

### 3. Rastreador de eventos
Un monitor en tiempo real para eventos sin procesar del sistema operativo. Muestra cada cambio de `mouse_click`, `key`, `redstone` o `modem_message` a medida que ocurre.

### 4. Analizador de piedra roja
Muestra niveles de entrada en vivo (0-15) para los seis lados de la computadora simultáneamente.

### 5. Explorador de archivos
Un navegador de directorio visual. Explore carpetas, vea tamaños de archivos y administre sus scripts sin comandos de terminal.

## ⚙️ Conectividad y navegación
- **Tecla de acceso rápido 'Q'**: regresa al menú anterior o sale de la herramienta.
- **Alternar red**: activar/desactivar la compatibilidad con Rednet y módem desde el menú principal.
- **Input Guard (NUEVO)**: Retrasos integrados de 0,5 s después de las entradas para evitar dobles clics accidentales al navegar por los menús.
