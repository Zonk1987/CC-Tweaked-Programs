## 🛠️ Ferramentas em destaque

### 1. Inspetor Periférico Superior
Substitui o scanner antigo. Selecione qualquer dispositivo para abrir uma lista de comandos interativa.
- **Setas (para cima/para baixo)**: Percorra todos os métodos disponíveis.
- **ENTER**: Execute o método selecionado e visualize os resultados em uma tabela formatada.
- **Tecla B**: inicia o **Navegador de itens interativo** (se o dispositivo for um inventário).

### 2. Navegador de itens interativo
Aprofunde-se em qualquer inventário (baús, interfaces AE2, provedores de padrões).
- **Setas (para cima/para baixo)**: percorrer os slots.
- **Detalhes ao vivo**: exibe metadados completos do item (tags NBT, danos, encantamentos, etc.) para o slot selecionado em tempo real.
- *Essencial para analisar estruturas internas do Padrão AE2.*

### 3. Sniffer de eventos
Um monitor em tempo real para eventos brutos do sistema operacional. Mostra cada mudança de `mouse_click`, `key`, `redstone` ou `modem_message` à medida que isso acontece.

### 4. Analisador Redstone
Exibe níveis de entrada ao vivo (0-15) para todos os seis lados do computador simultaneamente.

### 5. Explorador de arquivos
Um navegador de diretório visual. Navegue por pastas, visualize tamanhos de arquivos e gerencie seus scripts sem comandos de terminal.

## ⚙️ Conectividade e navegação
- **Atalho 'Q'**: Retorna ao menu anterior ou sai da ferramenta.
- **Alternância de rede**: Habilite/desabilite o suporte Rednet e Modem no menu principal.
- **Input Guard (NOVO)**: atrasos integrados de 0,5s após as entradas para evitar cliques duplos acidentais ao navegar nos menus.
