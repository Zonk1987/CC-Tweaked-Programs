## 🛠️ 特色工具

### 1. 高级周边检验员
更换旧扫描仪。选择任何设备以打开交互式命令列表。
- **箭头（向上/向下）**：滚动浏览所有可用方法。
- **ENTER**：执行所选方法并在格式化表格中查看结果。
- **B 键**：启动**交互式项目浏览器**（如果设备是库存设备）。

### 2. 交互式项目浏览器
深入研究任何库存（宝箱、AE2 接口、模式提供程序）。
- **箭头（向上/向下）**：滚动浏览插槽。
- **实时详细信息**：实时显示所选插槽的完整项目元数据（NBT 标签、损坏、结界等）。
- *分析 AE2 模式内部结构所必需的。*

### 3.事件嗅探器
原始操作系统事件的实时监视器。显示发生的每个“mouse_click”、“key”、“redstone”更改或“modem_message”。

### 4. 红石分析仪
同时显示计算机所有六个面的实时输入电平 (0-15)。

### 5. 文件资源管理器
可视化目录导航器。无需终端命令即可浏览文件夹、查看文件大小并管理脚本。
