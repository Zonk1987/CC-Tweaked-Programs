## 🚀Installation

1. Téléchargez le fichier install.lua depuis le dépôt

```bash

```

## 🛠️ Outils en vedette

### 1. Inspecteur périphérique supérieur
Remplace l'ancien scanner. Sélectionnez n’importe quel appareil pour ouvrir une liste de commandes interactive.
- **Flèches (haut/bas)** : faites défiler toutes les méthodes disponibles.
- **ENTER** : exécutez la méthode sélectionnée et affichez les résultats dans un tableau formaté.
- **Touche B** : lancez le **Navigateur d'objets interactif** (si l'appareil est un inventaire).

### 2. Navigateur d'éléments interactif
Plongez en profondeur dans n’importe quel inventaire (coffres, interfaces AE2, fournisseurs de modèles).
- **Flèches (haut/bas)** : faites défiler les emplacements.
- **Détails en direct** : affiche les métadonnées complètes des éléments (balises NBT, dégâts, enchantements, etc.) pour l'emplacement sélectionné en temps réel.
- *Indispensable pour analyser les structures internes du modèle AE2.*

### 3. Renifleur d'événements
Un moniteur en temps réel pour les événements bruts du système d'exploitation. Affiche chaque changement de `mouse_click`, `key`, `redstone` ou `modem_message` au fur et à mesure qu'il se produit.

### 4. Analyseur de Redstone
Affiche simultanément les niveaux d'entrée en direct (0-15) pour les six côtés de l'ordinateur.

### 5. Explorateur de fichiers
Un navigateur d'annuaire visuel. Parcourez les dossiers, affichez la taille des fichiers et gérez vos scripts sans commandes de terminal.

## ⚙️ Connectivité et navigation
- **Hotkey 'Q'** : revient au menu précédent ou quitte l'outil.
- **Bascule réseau** : activez/désactivez la prise en charge de Rednet et du modem à partir du menu principal.
- **Input Guard (NOUVEAU)** : délai intégré de 0,5 s après les entrées pour éviter les double-clics accidentels lors de la navigation dans les menus.
