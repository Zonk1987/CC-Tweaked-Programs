## 🚀 インストール

コンピュータで次のコマンドを実行します。

1. リポジトリから install.lua ファイルをダウンロードします。
```bash
wget https://raw.githubusercontent.com/Zonk1987/CC-Tweaked-Programs/main/install.lua
```
2. install.lua ファイルを実行します。
```bash
install.lua
```
メニューから **CC Developer Suite** を選択します。

## 🛠️ 注目のツール

### 1. 優秀な周辺機器検査官
古いスキャナーを交換します。任意のデバイスを選択して、対話型コマンド リストを開きます。
- **矢印 (上/下)**: 使用可能なすべての方法をスクロールします。
- **ENTER**: 選択したメソッドを実行し、結果をフォーマットされた表で表示します。
- **B キー**: **対話型アイテム ブラウザ** を起動します (デバイスがインベントリの場合)。

### 2. インタラクティブなアイテムブラウザ
あらゆるインベントリ (チェスト、AE2 インターフェイス、パターン プロバイダー) を詳しく調べます。
- **矢印 (上/下)**: スロットをスクロールします。
- **ライブ詳細**: 選択したスロットの完全なアイテム メタデータ (NBT タグ、ダメージ、エンチャントなど) をリアルタイムで表示します。
- *AE2パターンの内部構造解析に必須*

### 3. イベントスニファー
生の OS イベントのリアルタイム モニター。すべての「mouse_click」、「key」、「redstone」の変更、または「modem_message」を発生時に表示します。

### 4.レッドストーンアナライザー
コンピューターの 6 面すべてのライブ入力レベル (0 ～ 15) を同時に表示します。

### 5. ファイルエクスプローラー
視覚的なディレクトリナビゲーター。ターミナル コマンドを使用せずにフォルダーを参照し、ファイル サイズを表示し、スクリプトを管理します。

## ⚙️ 接続性とナビゲーション
- **ホットキー「Q」**: 前のメニューに戻るか、ツールを終了します。
- **ネットワーク切り替え**: メイン メニューから Rednet とモデムのサポートを有効/無効にします。
- **入力ガード (新機能)**: メニューをナビゲートする際の誤ったダブルクリックを防ぐために、入力後に 0.5 秒の遅延が統合されました。
