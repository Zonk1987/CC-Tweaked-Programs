## 🚀 Installation

Run this command on your computer:

1. Download the install.lua file from the repo
```bash
wget https://raw.githubusercontent.com/Zonk1987/CC-Tweaked-Programs/main/install.lua
```
2. Run the install.lua file
```bash
install.lua
```
Select **CC Developer Suite** from the menu.

## 🛠️ Featured Tools

### 1. Superior Peripheral Inspector
Replaces the old scanner. Select any device to open an interactive command list.
- **Arrows (Up/Down)**: Scroll through all available methods.
- **ENTER**: Execute the selected method and view the results in a formatted table.
- **B key**: Launch the **Interactive Item Browser** (if the device is an inventory).

### 2. Interactive Item Browser
Deep-dive into any inventory (Chests, AE2 Interfaces, Pattern Providers).
- **Arrows (Up/Down)**: Scroll through slots.
- **Live Details**: Displays full item metadata (NBT tags, damage, enchantments, etc.) for the selected slot in real-time.
- *Essential for analyzing AE2 Pattern internal structures.*

### 3. Event Sniffer
A real-time monitor for raw OS events. Shows every `mouse_click`, `key`, `redstone` change, or `modem_message` as it happens.

### 4. Redstone Analyzer
Displays live input levels (0-15) for all six sides of the computer simultaneously.

### 5. File Explorer
A visual directory navigator. Browse folders, view file sizes, and manage your scripts without terminal commands.

## ⚙️ Connectivity & Navigation
- **Hotkey 'Q'**: Returns to the previous menu or exits the tool.
- **Network Toggle**: Enable/Disable Rednet and Modem support from the main menu.
- **Input Guard (NEW)**: Integrated 0.5s delays after inputs to prevent accidental double-clicks when navigating menus.
