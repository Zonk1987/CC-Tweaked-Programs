# Universal Automation Installer (CC:Tweaked)

> A robust, modular installation system for the **Zonk1987** automation ecosystem. Designed for professional-grade deployment with full GitHub integration and offline-ready fallback mechanisms.

---

## 🚀 Quick Start
Run this single command on any ComputerCraft terminal to launch the installer:

```bash
wget https://raw.githubusercontent.com/Zonk1987/CC-Tweaked-Programs/dev/Universal%20Installer/install.lua
install
```

---

## 🛠️ Key Features
- **GitHub API Integration** — Automatically fetches the latest versions of all scripts directly from the source.
- **Offline Fallback** — Includes a hardcoded project manifest to ensure core tools can still be installed if the GitHub API is unavailable.
- **Full Dependency Management** — Downloads all required modules, libraries, and assets for each project automatically.
- **Automatic Setup** — Sets up `startup` files and reboots the computer to ensure immediate operational readiness.
- **Clean UI** — Professional terminal interface with clear progress indicators and success messages.
