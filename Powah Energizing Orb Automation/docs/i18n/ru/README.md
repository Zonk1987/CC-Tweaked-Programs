# Автоматизация энергетической сферы Пова (CC:Tweaked)

> Полностью автоматизированная, готовая к производству система ComputerCraft для **Энергетических сфер** из мода **Powah**. Поддерживает параллельную обработку, расширенную интеграцию AE2 и интеллектуальную совместимость с модпаками.


---

## ✨ Особенности

- **Поддержка нескольких сфер** — автоматически обнаруживает все подключенные энергетические сферы и создает их параллельно.
- **Интеграция ME Bridge (требуется)** — использует `meBridge` от Advanced Peripherals для чтения подробных данных шаблона AE2 (входы, выходы, количества).
- **Прямой доступ к провайдеру (необязательно)** — Полная поддержка мода **`ae2communicate`**. В сочетании с ME Bridge он позволяет фильтровать рецепты по **именованным поставщикам шаблонов**, устраняя необходимость поиска в крупных сетях.
- **Точность и интеллект** — Автоматическая обработка множителей и точная проверка ингредиентов на основе идентификатора во время импорта.
- **Совместимость с пакетами модов** — переключайтесь между «Только Powah» или «Все моды» (клавиша `M`), чтобы поддерживать рецепты из любого мода с помощью Energizing Orb.
- **Автовосстановление** — автоматическое извлечение предметов и сброс сфер в случае сбоев в работе или сбоев в подаче электроэнергии.

## 🛠️ Настройка оборудования

![Ingame Setup](../../assets/images/orb-setup.png)


1. **Продвинутый компьютер** — требуется для цветной приборной панели с высоким разрешением.
2. **Буферный сундук**. Подключите любой сундук (например, Алмазный сундук), расположенный рядом с компьютером или через сеть.
3. **Сферы энергии** — соедините все сферы с помощью **сетевых кабелей** и **проводных модемов**.
4. **Мост ME (обязательно):** Подключите **Мост ME** к сети, чтобы система могла считывать подробные данные шаблонов.
5. **Дополнительная функция качества жизни (ae2communicate):**
- Установите мод **`ae2communicate`**.
- Поместите **Проводной модем** непосредственно на **Интерфейс AE2** (распознаваемый как `ae2_scanner`).
- Назовите поставщиков шаблонов в своей системе AE2 (например, «Сфера Пауа»).
- **Преимущество:** фильтрует данные ME Bridge, чтобы отображать шаблоны только от этого конкретного поставщика!

## 🚀 Установка и использование

1. Загрузите файл install.lua из репозитория.
```bash
wget https://raw.githubusercontent.com/Zonk1987/CC-Tweaked-Programs/main/install.lua
```
2. Запустите файл install.lua.
```bash
install.lua
```
3. В меню выберите **Автоматизация Powah**.
4. Система автоматически обнаруживает периферийные устройства при запуске.
5. **Важно**: установите для поставщиков шаблонов AE2 режим **"Режим блокировки"** и направьте их на буферный сундук.

## 📖 Импорт рецептов AE2

В системе имеется интеллектуальное меню импорта (Клавиша **`I`**):

### Сценарий А: с дополнительным сканером AE2
1. Нажмите **`I`**.
2. Выберите **Именованный поставщик шаблонов**, из которого вы хотите выполнить импорт.
3. Просмотрите отфильтрованные рецепты и нажмите **`ENTER`** для импорта.

### Сценарий B: Стандартный (только мост ME)
1. Нажмите **`I`**.
2. Просмотрите все доступные шаблоны в сети.
3. Используйте **`M`** для переключения между **Только Powah** и **Все моды**.
4. Нажмите **`ENTER`** для импорта.

## ⌨️ Горячие клавиши

| Ключ | Действие |
|:---:|---|
| **`Р`** | **Перезагружайте** рецепты без перезапуска. |
| **`Я`** | **Меню «Импорт»** (просмотр и добавление шаблонов AE2) |
| **`М`** | **Переключение модов** (Внутреннее меню импорта: Powah против всех. *Доступно только в том случае, если НЕ используется мод «ae2communicate»*) |
| **`Б`** | **Назад** (внутри меню импорта: возврат к выбору поставщика) |
| **`X`** | **Удалить** (удалить импортированный рецепт из системы) |
| **`Q`** | **Выход** (выйдите из меню импорта и вернитесь на панель управления) |

## ⚙️ Конфигурация

Система предназначена для работы «из коробки». Если вам нужны ручные настройки, проверьте `startup.lua`:
```lua
local system = PowahSystem.new({
    chestName = "left", -- Or use auto-detection variable
    recipeFile = "powah_recipes.json",
    meBridgeName = "right", -- Required for imports: ME Bridge peripheral name
    aeScannerName = "top" -- Optional: ae2communicate scanner peripheral name
})
```

## 🛑 Устранение неполадок

| Ошибка | Причина и решение |
|---|---|
| `Мост ME не найден!` | Проверьте кабели и состояние модема. |
| `Сканер AE: Нет` | Нормально, если у вас нет мода. Будет использован классический режим. |
| `Тайм-аут в Сфере...` | Создание заняло >60 секунд. Предметы вернулись в сундук. Проверьте мощность! |
| `Повторяющееся имя` | Вы пытаетесь импортировать уже существующий рецепт. |
