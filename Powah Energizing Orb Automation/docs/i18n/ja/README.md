- **マルチオーブのサポート** — 接続されているすべてのエネルギーオーブとクラフトを並行して自動的に検出します。
- **ME ブリッジ統合 (必須)** — Advanced Peripherals の「meBridge」を使用して、詳細な AE2 パターン データ (入力、出力、数量) を読み取ります。
- **ダイレクト プロバイダー アクセス (オプション)** — **`ae2communicate`** mod を完全にサポートします。 ME Bridge と組み合わせると、**名前付きパターン プロバイダー** でレシピをフィルタリングできるため、大規模なネットワークを介して検索する必要がなくなります。

- **自動回復** — クラフトの停止や停電の場合に、アイテムの自動取得とオーブのリセットが行われます。

## 📖 AE2レシピインポート

このシステムには、スマート インポート メニュー (キー **`I`**) が備わっています。

### シナリオ A: オプションの AE2 スキャナーを使用する場合
1. **「I」** を押します。
2. インポート元の **名前付きパターン プロバイダー** を選択します。
3. フィルタリングされたレシピを参照し、**`ENTER`** を押してインポートします。

### シナリオ B: 標準 (ME ブリッジのみ)
1. **「I」** を押します。
2. ネットワーク内で使用可能なすべてのパターンを参照します。
3. **`M`** を使用して、**Powah のみ** と **すべての Mods** を切り替えます。
4. **`ENTER`** を押してインポートします。

## ⌨️ ホットキー

| 鍵 | アクション |
|:---:|---|
| **`R`** | 再起動せずに**レシピをリロード** |
| **「私は」** | **インポート メニュー** (AE2 パターンの参照と追加) |

| **「Q」** | **終了** (インポート メニューを終了し、ダッシュボードに戻ります) |
