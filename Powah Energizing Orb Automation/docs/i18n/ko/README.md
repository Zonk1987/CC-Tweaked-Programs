# 포와 에너자이징 오브 자동화(CC:Tweaked)

> **Powah** 모드의 **Energizing Orbs**를 위한 완전 자동화되고 생산 준비가 완료된 ComputerCraft 시스템입니다. 병렬 처리, 고급 AE2 통합 및 지능형 모드팩 호환성을 지원합니다.


---

## ✨ 특징

- **다중 오브 지원** — 연결된 모든 에너자이징 오브와 공예품을 동시에 자동으로 검색합니다.
- **ME Bridge 통합(필수)** — 고급 주변 장치의 'meBridge'를 사용하여 자세한 AE2 패턴 데이터(입력, 출력, 수량)를 읽습니다.
- **직접 공급자 액세스(선택 사항)** — **`ae2communicate`** 모드를 완벽하게 지원합니다. ME Bridge와 페어링하면 **명명된 패턴 제공자**별로 레시피를 필터링할 수 있으므로 대규모 네트워크를 통해 검색할 필요가 없습니다.
- **정밀성 및 지능** — 가져오는 동안 승수 자동 처리 및 정확한 ID 기반 성분 검증.
- **모드팩 호환성** — "Powah Only" 또는 "All Mods"(키 `M`) 사이를 전환하여 에너자이징 오브를 사용하는 모든 모드의 레시피를 지원합니다.
- **자동 복구** — 제작이 중단되거나 정전되는 경우 자동으로 아이템을 검색하고 구체를 재설정합니다.

---

## 🛠️ 하드웨어 설정

![Ingame Setup](../../assets/images/orb-setup.png)


1. **고급 컴퓨터** — 고해상도 컬러 대시보드에 필요합니다.
2. **버퍼 상자** — 컴퓨터에 인접한 상자(예: 다이아몬드 상자)를 연결하거나 네트워크를 통해 연결합니다.
3. **에너지 충전 오브** — **네트워킹 케이블** 및 **유선 모뎀**을 통해 모든 오브를 연결합니다.
4. **ME 브리지(필수):** 시스템이 세부 패턴 데이터를 읽을 수 있도록 **ME 브리지**를 네트워크에 연결합니다.
5. **선택적 삶의 질 기능(ae2communicate):**
- **ae2communicate`** 모드를 설치하세요.
- **AE2 인터페이스**(`ae2_scanner`로 인식됨)에 **유선 모뎀**을 직접 배치합니다.
- AE2 시스템에서 패턴 제공자의 이름을 지정하십시오(예: "Powah Orb").
- **이점:** ME Bridge 데이터를 필터링하여 이 특정 공급자의 패턴만 표시합니다!

## 🚀 설치 및 사용

1. 저장소에서 install.lua 파일을 다운로드합니다.
```bash
wget https://raw.githubusercontent.com/Zonk1987/CC-Tweaked-Programs/main/install.lua
```
2. install.lua 파일을 실행하세요
```bash
install.lua
```
3. 메뉴에서 **Powah Automation**을 선택합니다.
4. 시스템은 시작 시 주변 장치를 자동으로 감지합니다.
5. **중요**: AE2 패턴 제공자를 **"차단 모드"**로 설정하고 버퍼 상자를 가리킵니다.

## 📖 AE2 레시피 가져오기

시스템에는 스마트 가져오기 메뉴(키 **`I`**)가 있습니다.

### 시나리오 A: 옵션 AE2 스캐너 사용
1. **`I`**를 누르세요.
2. 가져오려는 **명명된 패턴 제공자**를 선택합니다.
3. 필터링된 레시피를 탐색하고 **`ENTER`**를 눌러 가져옵니다.

### 시나리오 B: 표준(ME Bridge만 해당)
1. **`I`**를 누르세요.
2. 네트워크에서 사용 가능한 모든 패턴을 찾아보세요.
3. **`M`**을 사용하여 **Powah Only**와 **All Mods** 사이를 전환합니다.
4. 가져오려면 **`ENTER`**를 누르세요.

## ⌨️ 단축키

| 열쇠 | 행동 |
|:---:|---|
| **`R`** | 다시 시작하지 않고 레시피 **다시 로드** |
| **`나`** | **가져오기 메뉴**(AE2 패턴 검색 및 추가) |
| **`엠`** | **Mod Toggle** (가져오기 메뉴 내부: Powah vs. All. *'ae2communicate' 모드를 사용하지 않는 경우에만 사용 가능*) |
| **`B`** | **뒤로** (가져오기 메뉴 내부: 공급자 선택으로 돌아갑니다) |
| **`X`** | **삭제**(가져온 레시피를 시스템에서 제거) |
| **`Q`** | **종료**(가져오기 메뉴를 종료하고 대시보드로 돌아가기) |

## ⚙️ 구성

이 시스템은 기본적으로 작동하도록 설계되었습니다. 수동 조정이 필요한 경우 `startup.lua`를 확인하세요.
```lua
local system = PowahSystem.new({
    chestName = "left", -- Or use auto-detection variable
    recipeFile = "powah_recipes.json",
    meBridgeName = "right", -- Required for imports: ME Bridge peripheral name
    aeScannerName = "top" -- Optional: ae2communicate scanner peripheral name
})
```
